# CCAN steering group briefings (static site)

Three pages that talk to one Google Apps Script web app:

- `/` the members' briefing (My asks)
- `/add/` the Add asks page
- `/pm/?pm=<private key>` the project-manager view (open it once with the key; the device remembers it)

Built by the briefing-engine skill (scripts/build-static.js). Nothing secret is stored in these files.
Web app: https://script.google.com/macros/s/AKfycbzwgTSPj-I2Of1LXBnbeF2Tegf_s92Wu26Lgl6o9lfNrJqEs8lBw1-3yJ5wmo2OYwIJ/exec
